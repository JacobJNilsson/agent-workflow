---
name: no-emdash-no-semicolon
description: Writing style rule, never use em-dashes or semicolons in any output
metadata:
  type: feedback
---

Never use em-dashes or semicolons in any written output: commit messages,
PR titles and descriptions, code comments, and chat prose.

**Why:** explicit user instruction.

**How to apply:** replace an em-dash with a comma, parentheses, or a full
stop. Replace a semicolon with a full stop, a comma, or a connecting word
like "and". Hyphens in compound words (auto-recover, 401-vs-403) are
fine. Applies when rewriting existing text too.
